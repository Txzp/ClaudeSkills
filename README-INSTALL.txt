- SKILL.md: Skill principal para Claude.

INSTALACIÓN EN CLAUDE.AI
1. Conserva la carpeta airskills-roblox-blender.
2. Comprime la carpeta como ZIP si aún no está comprimida.
3. En Claude, abre Settings > Capabilities (o Features, según la interfaz) > Skills.
4. Activa la función de ejecución de código si Claude la solicita.
5. Sube el ZIP de la carpeta de la skill.
6. Activa la skill y comienza un encargo de modelado 3D.

INSTALACIÓN EN CLAUDE CODE
Copia la carpeta airskills-roblox-blender dentro de:
- Proyecto: .claude/skills/airskills-roblox-blender/
- Usuario: ~/.claude/skills/airskills-roblox-blender/

Asegúrate de que SKILL.md quede dentro de esa carpeta.
